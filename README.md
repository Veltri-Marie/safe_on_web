
# Sentinel

Sentinel est une extention innovante de censure et de modération de contenu, développée dans le cadre d’un hackathon au MIC.

L’objectif de Sentinel est de rendre la navigation web plus sûre en détectant et en filtrant automatiquement les propos injurieux, haineux ou inappropriés, que ce soit sur des sites web ou via une extension navigateur.

L’application se compose de trois volets complémentaires :
- **Un backend .NET** qui analyse et traite les contenus grâce à l’intelligence artificielle (Azure OpenAI).
- **Un frontend web** pour visualiser et tester la censure de contenus.
- **Une extension navigateur** permettant d’activer la modération en temps réel sur n’importe quelle page web.
